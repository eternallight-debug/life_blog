玩法说明

鼠标

  • 柱子上 左键 → 拿起最上面的盘子，跟随鼠标移动。
  • 任意柱子上 左键或右键 → 放下盘子。

键盘

  • A S D 对应 左 / 中 / 右 三根柱子（1 2 3 同效）。
  • 空手按键 → 在该柱子上方举起盘子，不跟随鼠标。
  • 手上有盘子时按键 → 放到对应柱子上。

其他

  • R → 重新开始，空格 确认。
目标：把所有盘子从最左边移到最右边，且始终保持「大在下、小在上」。

基本设定

  • 三根柱子，若干个大小各不相同的圆盘。
  • 初始时全部按「大在下、小在上」叠在最左边。

移动规则

  • 每次只能移动一个圆盘。
  • 只能拿某根柱子最上面的那一个。
  • 任何时刻，大盘子都不能压在小盘子上面。

胜利条件

  • 把所有圆盘完整移到最右边，顺序依然是「大在下、小在上」。
最少步数 = 2n − 1。3 盘 7 步，4 盘 15 步，5 盘 31 步，10 盘 1023 步。

从何而来

汉诺塔（Tower of Hanoi）由法国数学家 爱德华·卢卡斯（Édouard Lucas） 于 1883 年首次介绍给公众，因此也被称为「卢卡斯塔」。

那个著名的传说

传说在印度贝拿勒斯的寺庙里，梵天立起三根钻石针，在其中一根上自下而上串起了 64 片金盘。僧侣们日夜不停地按照规则搬运。

传说当 64 片金盘全部被搬到另一根针上时，世界将在一声霹雳中毁灭。

算一算

  • 64 片金盘需要 264 − 1 ≈ 1.845 × 1019 次移动。
  • 每秒移动一次，需要约 5845 亿年。
  • 而宇宙年龄约 138 亿年——暂时可以放心。

核心思路

把 n 个盘子从起点 A 搬到目标 C，借助辅助 B：

  • 把上面 n − 1 个从 A 搬到 B（借助 C）。
  • 把最大的第 n 个从 A 直接搬到 C。
  • 把 B 上的 n − 1 个搬到 C（借助 A）。

第 1 步和第 3 步是规模更小的同类问题，于是「自己调用自己」——这就是递归。

伪代码

function hanoi(n, from, to, via):
    if n == 1:
        把盘子从 from 移到 to
    else:
        hanoi(n-1, from, via, to)
        把第 n 个盘子从 from 移到 to
        hanoi(n-1, via, to, from)

步数为什么是 2ⁿ − 1

T(n) = 2·T(n − 1) + 1，T(1) = 1，展开得 T(n) = 2n − 1。 每多一个盘子，步数就「翻倍再加一」：1 → 3 → 7 → 15 → 31 → …

而且最优解唯一——任何时刻正确的下一步几乎是确定的。
